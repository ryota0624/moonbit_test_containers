# Steering: マルチエージェントシステムの構築

## 目的・背景
Claude Codeでの開発作業を効率化するため、役割を分担した複数のエージェントシステムを構築する。各エージェントが専門的な役割を担うことで、作業の品質と効率を向上させる。

## ゴール
- 5つの役割を持つエージェントを定義
- オーケストレータが他のエージェントを統制する構成
- `.claude/agents`ディレクトリに各エージェントの定義を配置
- 各エージェントの責務と連携方法を明確化

## アプローチ
- 各エージェントをmarkdownファイルで定義
- エージェントの役割、責務、入出力、使用するツールを明示
- オーケストレータが作業を解釈し、適切なエージェントに委譲するフローを設計

## スコープ

### 含むもの
- オーケストレータ: 作業の解釈と委譲
- テストアーキテクト: 動作検証方法の考察と設計
- ソフトウェアアーキテクト: 技術的方針の策定
- コーダー: 実際のコーディング
- レビュアー: コードレビュー

### 含まないもの
- 実際のコード実装（エージェント定義のみ）
- エージェント間の自動連携機能（手動で呼び出す想定）

## 影響範囲
- 新規作成: `.claude/agents/` ディレクトリ配下の5つのmarkdownファイル
- 新規作成: `docs/steering/multi-agent-system.md`（本ファイル）
- 将来的な作業完了後: `docs/completed/multi-agent-system.md`

## エージェント連携フロー
```
ユーザーリクエスト
    ↓
オーケストレータ
    ↓
    ├─→ ソフトウェアアーキテクト（技術方針策定）
    ├─→ テストアーキテクト（テスト方針策定）
    ↓
    ├─→ コーダー（実装）
    ↓
    └─→ レビュアー（レビュー）
```
